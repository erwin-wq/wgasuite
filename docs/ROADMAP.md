# Roadmap

## Fase 1: MVP foundation

- Projectstructuur
- Basis datamodel
- CRUD-start voor organisaties, assessments en findings
- DREAD-scoreberekening
- Docker Compose
- CI lint/test/build

## Fase 2: Workflow

- Detailpagina's en update/delete acties
- Assessment statusovergangen
- Finding severity banding
- Filters en sortering
- Basis rapportage in de UI

## Fase 3: Security baseline

- Authenticatie
- Rollen en permissies
- Audit logging
- Rate limiting
- Striktere inputvalidatie en security headers

## Portal & Roles

- Customer Portal
- Platform Admin Portal
- Role-based access control
- Customer membership
- Support access logging
- Audit logging

## Fase 4: Connectoren

- Connector abstraction
- Google Workspace OAuth ontwerp
- Read-only inventory import
- Connector health/status scherm
- Tokenopslag via veilige secret storage

## Fase 5: Rapportage en integraties

- Export naar PDF/CSV
- Webhooks
- Ticketing-integraties
- Management dashboards
